# Website v3
I've made a ton of personal websites before, but im not liking my current one. It's too boilerplatey, too fancy. I want one that just looks simple and nice.
So this is that! It's made in plain astro, without any fancy tailwind or anything that i normally use on my sites. All the pages build to be completely static, so the page loads are really fast.

Pages:
/ - the main portfolio and homepage
/contact - email and hack club slack details
/photography - a set of some of the photos that I'm most happy with that I've taken.

Images all use hack club cdn.

## Building and developing
This project uses pnpm for a package manager. Therefore, you can simply run

```pnpm i```

and then:

```pnpm dev```
